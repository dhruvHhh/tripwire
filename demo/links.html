Dynamic page tests

Everything in this section changes the page after it has loaded. Keep the Tripwire popup open while you try them: its numbers update as you go.

Inject 500 links

Adds 500 links at once: 450 ordinary, 25 amber and 25 red, each to a different address. The page doesn't freeze, and within a second the toolbar count rises by 25 and the popup's numbers by 500, 25 and 25. "Remove them" takes the counts back down.

Link whose address changes

Starts green. Press the button and it turns red without a reload, and the toolbar count goes up by one. Press again and it is green again.

Single-page navigation

These buttons change the address with history.pushState, without loading a page. On localhost nothing else changes. To see verdicts change, open this page as http://one.two.three.four.tripwire.localhost:8080/ and press the first button. A very long address on top of that many subdomains makes the page itself suspicious, so the same-site links (the logo, "Docs" and "About this page") turn amber and the popup shows a page warning. The second button turns them green again.

Shadow roots

Box 1 is an open shadow root: its links get badges like any others, and its button adds a red link that gets one too. Box 2 is a custom element whose definition loads when you press its button: its red link gets a badge shortly after. Box 3 is a closed shadow root: Tripwire does not look inside, so its red link gets no badge and is not counted.
